# YOUMMA Business

YOUMMA Business — logiciel de gestion de boutique (caisse, stock, clients & crédits). Un produit YOUMMA SARLU.

## Lancer en local

Depuis le dossier du projet :

```bash
npx serve .
```

Puis ouvrir l’adresse affichée (par exemple http://localhost:3000).

Les paramètres Supabase (URL du projet et clé publique) sont dans `js/config.js`.
